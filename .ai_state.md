## 🧠 Dev Notes & Hypotheses

- `state.db` is opened fresh per-request (no connection pool). This is fine for SQLite under low concurrency but will serialize writes under load. A singleton connection or `aiosqlite` pool should be considered when concurrent correction submissions become a concern.
- `ADMIN_SECRET_KEY` defaults to `""`. In production, if the operator forgets to set it, the vacuum and `/pending` endpoints become permanently inaccessible (403 on every request). Consider a startup warning log if `APP_ENV == "production"` and `ADMIN_SECRET_KEY` is empty.
- The `get_count_suffix` function only handles Russian ordinal declension for use in search result headers. It is not a general-purpose inflection utility — do not extend it without considering `pymorphy2` or a lookup table approach.
- `source_view.html` uses `| safe` on `line_html`. This is safe as long as `line_html` is exclusively ingest-produced. If the corrections pipeline ever writes back to corpus lines, this assumption must be re-examined.
