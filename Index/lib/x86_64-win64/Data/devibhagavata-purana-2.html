Скандха 2
ГЛАВА ПЕРВАЯ. ПОЯВЛЕНИЕ НА СВЕТ МАТСЬЯГАНДХИ
1
ṛṣaya ūcuḥ
āścaryakarametatte vacanaṃ garbhahetukam
sandeho'tra samutpannaḥ sarveṣāṃ nastapasvinām // 2.1.1 //
Мудрецы:
Твои слова удивительны, Но сомнение возникло [вследствие слушания] их у нас всех, у подвижников.
2
mātā vyāsasya medhāvinnāmnā satyavatīti ca
vivāhitā purā jnātā rājnā śantanunā yathā // 2.1.2 //
Мудрецы:
[Мы знаем, что] мать Вьясы1 по имени Сатьявати2, о мудрец, Была прежде выдана замуж за царя Шантану3.
3
tasyāḥ putraḥ kathaṃ vyāsaḥ satī svabhavane sthitā
īdṛśī sā kathaṃ rājnā punaḥ śantanunā vṛtā // 2.1.3 //
Мудрецы:
Как же Вьяса стал ее сыном, и как целомудренная, оставаясь в своем доме, Была выдана замуж за Шантану?
4
tasyāṃ putrāvubhau jātau tattvaṃ kathaya suvrata
vistareṇa mahābhāga kathāṃ paramapāvanīm // 2.1.4 //
Мудрецы:
И как у нее родилось два сына, правду расскажи, о давший благой обет, Подробно, о обладатель великой доли4, [сообщи] повествование, очищающее в высшей степени.
5
utpattiṃ vada vyāsasya satyavatyāstathā punaḥ
śrotukāmāḥ punaḥ sarve ṛṣayaḥ saṃśitavratāḥ // 2.1.5 //
Мудрецы:
О рождении Ведавьясы5 и Сатьявати снова Желают услышать все [мудрецы], стойкие в обетах.
6
sūta uvāca
praṇamya paramāṃ śaktiṃ caturvargapradāyinīm
ādiśaktiṃ vadiṣyāmi kathāṃ paurāṇikīṃ śubhām // 2.1.6 //
Сута:
Склонившись перед Высшей Шакти7, помогающей достигнуть четырех целей человеческой жизни8, [Приветствуя] изначальную Шакти, я поведую благую пураническую историю9.
7
sūta uvāca
yasyoccāraṇamātreṇa siddhirbhavati śāśvatī
vyājenāpi hi bījasya vāgbhavasya viśeṣataḥ // 2.1.7 //
Сута:
От произносения даже под [каким-либо] предлогом Биджа-[мантры] Вагбхавы 10 Бывает счастье вечное.
8
sūta uvāca
samyak sarvātmanā sarvaiḥ sarvakāmārthasiddhaye
smartavyā sarvathā devī vānchitārthapradāyinī // 2.1.8 //
Сута:
Всеми силами ради исполнения желаний и удачи Надо держать в памяти [образ] Богини11, подательницы желанных благ.
9
sūta uvāca
rājoparicaro nāma dhārmikaḥ satyasaṇgaraḥ
cedideśapatiḥ śrīmān babhūva dvijapūjakaḥ // 2.1.9 //
Сута:
[Некогда] был царь по имени Упаричара12, повелитель страны Чеди13, Праведный, правдивый в обещаниях, прекрасный, почитающий брахманов14.
10
sūta uvāca
tapasā tasya tuṣṭena vimānaṃ sphāṭikaṃ śubham
dattamindreṇa tattasmai sundaraṃ priyakāmyayā // 2.1.10 //
Сута:
Довольный его подвижничеством, Индра15 даровал ему Прекрасную небесную колесницу16, желая доставить [ему] приятное.
11
sūta uvāca
tenārūḍhastu sarvatra yāti divyena bhūpatiḥ
na bhūmāvuparistho'sau tenoparicaro vasuḥ // 2.1.11 //
Сута:
Взойдя на эту божественную колесницу, царь путешествовал повсюду, И не останавливался на Земле, поэтому как Упаричара Васу17
12
sūta uvāca
vikhyātaḥ sarvalokeṣu dharmanityaḥ sa bhūpatiḥ
tasya bhāryā varārohā girikā nāma sundarī // 2.1.12 //
Сута:
Тот вечно праведный царь стал известен во всех мирах. У него была жена, дивнобедрая красавица по имени Гирика18,
13
sūta uvāca
putrāścāsya mahāvīryāḥ pancāsannamitaujasaḥ
pṛthagdeśeṣu rājānaḥ sthāpitāstena bhūbhujā // 2.1.13 //
Сута:
И пять могучих сыновей, исполненных неизмеримой доблести. Их царь поставил правителями в различных странах19.
14
sūta uvāca
vasostu patnī girikā kāmān kāle nyavedayat
ṛtukālamanuprāptā snātā puṃsavane śuciḥ // 2.1.14 //
Сута:
Супруга Васу Гирика, достигнув времени месячных, совершила омовение, И очистившись, сообщила ему о желании получить [еще одного] сына20.
15
sūta uvāca
tadahaḥ pitaraścainamūcurjahi mṛgāniti
tacchrutvā cintayāmāsa bhāryāmṛtumatīṃ tathā // 2.1.15 //
Сута:
В тот день предки сказали ему: «Настреляй оленей! [для шраддхи21] « И услышав это, он подумал о своей жене, достигшей времени месячных.
16
sūta uvāca
pitṛvākyaṃ guruṃ matvā kartavyamiti niścitam
cacāra mṛgayāṃ rājā girikāṃ manasā smaran // 2.1.16 //
Сута:
Царь посчитал просьбу предков более важной, и решив, что она должна быть исполнена, отправился на охоту, вспоминая Гирику.
17
sūta uvāca
vane sthitaḥ sa rājarṣiścitte sasmāra bhāminīm
atīva rūpasampannāṃ sākṣācchriyamivāparām // 2.1.17 //
Сута:
Находясь в лесу, царь-мудрец вспоминал супругу, Наделенную великой красотой, подобную второй Шри22.
18
sūta uvāca
tasya retaḥ pracaskanda smaratastāṃ ca kāminīm
vaṭapatre tu tadrājā skannamātraṃ samākṣipat // 2.1.18 //
Сута:
В то время, как он думал о красавице, у него случилось извержение семени, И на листе баньяна23 царь сохранил вытекшее семя.
19
sūta uvāca
idaṃ vṛthā pariskannaṃ reto vai na bhavetkatham
ṛtukālaṃ ca vijnāya matiṃ cakre nṛpastadā // 2.1.19 //
Сута:
«Пусть не напрасным будет извержение семени», — Зная о времени месячных, царь сосредоточил на этом мысль тогда.
20
sūta uvāca
amoghaṃ sarvathā vīryaṃ mama caitanna saṃśayaḥ
priyāyai preṣayāmyetaditi buddhimakalpayat // 2.1.20 //
Сута:
«Мое будет не бесплодным семя, без сомнения, Любимой я отошлю его», — так он подумал.
21
sūta uvāca
śukraprasthāpane kālaṃ mahiṣyāḥ prasamīkṣya saḥ
abhimantryātha tadvīryaṃ vaṭaparṇapuṭe kṛtam // 2.1.21 //
Сута:
Затем, считая, что должное время для отправки семени царице подошло, Он произнес мантры и спрятал его под листья баньяна.
22
sūta uvāca
pārśvasthaṃ śyenamābhāṣya rājovāca dvijaṃ prati
gṛhāṇedaṃ mahābhāga gaccha śīghraṃ gṛhaṃ mama // 2.1.22 //
Сута:
К находящемуся поблизости соколу обратившись, царь сказал птице: «Возьми это, о обладатель великой доли, и лети поспешно в мой дворец.
23
sūta uvāca
matpriyārthamidaṃ saumya gṛhītvā tvaṃ gṛhaṃ naya
girikāyai prayacchāśu tasyāstvārtavamadya vai // 2.1.23 //
Сута:
Ради моей жены, взяв это, ты во дворец лети, И Гирике передай поскорей, так как у нее сейчас месячные.
24
sūta uvāca
ityuktvā pradadau parṇaṃ śyenāya nṛpasattamaḥ
sa gṛhītvotpapātāśu gaganaṃ gativittamaḥ // 2.1.24 //
Сута:
Произнеся такие слова, лучший из царей отдал лист соколу, И он, взяв его, взмыл высоко в небо, способный быстро летать.
25
sūta uvāca
gacchantaṃ gaganaṃ śyenaṃ dhṛtvā cancupuṭe puṭam
tamapaśyadathāyāntaṃ khagaṃ śyenastathāparaḥ // 2.1.25 //
Сута:
[Этого] сокола, летящего в небе и держащего в клюве лист, Увидел другой сокол,
26
sūta uvāca
āmiṣaṃ sa tu vijnāya śīghramabhyadravatkhagam
tuṇḍayuddhamathākāśe tāvubhau sampracakratuḥ // 2.1.26 //
Сута:
И думая, что это кусок мяса, поспешно на него напал. Тогда оба они начали драться в воздухе клювами.
27
sūta uvāca
yud|hdhyatorapatadretastajjāpi yamunāmbhasi
khagau tau nirgatau kāmaṃ puṭake patite tadā // 2.1.27 //
Сута:
Когда они сражались, семя упала в воды Ямуны24, И оба сокола разлетелись, куда хотели, когда лист упал.
28
sūta uvāca
etasminsamaye kācidadrikā nāma cāpsarāḥ
brāhmaṇaṃ samanuprāptaṃ sandhyāvandanatatparam // 2.1.28 //
Сута:
В это самое время апсара25 по имени Адрика26 Пришла к брахману, совершающему сандхья-вандану27.
29
sūta uvāca
kurvantī jalakeliṃ sā jale magnā cacāra sā
jagrāha caraṇaṃ nārī dvijasya varavarṇinī // 2.1.29 //
Сута:
Резвясь в воде, красавица, погруженная в воду, приблизилась И ухватила брахмана за ногу28.
30
sūta uvāca
prāṇāyāmaparaḥ so'tha dṛṣṭvā tāṃ kāmacāriṇīm
śaśāpa bhava matsyī tvaṃ dhyānavighnakarī yataḥ // 2.1.30 //
Сута:
3анятый пранаямой29, он, увидев ее, пришедшую ради любви, Наложил на нее проклятие: «Стань рыбой, потому что ты прервала мое созерцание».
31
sūta uvāca
sā śaptā vipramukhyena babhūva yamunācarī
śapharī rūpasampannā hyadrikā ca varāpsarāḥ // 2.1.31 //
Сута:
Адрика, лучшая из апсар, проклятая главным из брахманов, Стала жить в Ямуне [как рыба] шапхари30, наделенная красотой.
32
sūta uvāca
śyenapādaparibhraṣṭaṃ tacchukramatha vāsavī
jagrāha tarasābhyetya sādrikā matsyarūpiṇī // 2.1.32 //
Сута:
К выроненному соколом семени, Адрика, пребывающая в облике рыбы, быстро подплыла, проглотила его и понесла плод.
33
sūta uvāca
atha kālena kiyatā matsyīṃ tāṃ matsyajīvanaḥ
samprāpte daśame māsi babandha tāṃ manoramām // 2.1.33 //
Сута:
Затем со временем, по прошествии десяти месяцев, Рыбак поймал ту прекрасную рыбу.
34
sūta uvāca
udaraṃ vidadārāśu sa tasyā matsyajīvanaḥ
yugmaṃ viniḥsṛtaṃ tasmādudarānmānuṣākṛti // 2.1.34 //
Сута:
[Когда] рыбак разрезал ее брюхо, То из него вышла пара [существ], имеющих человеческий облик31,
35
sūta uvāca
bālaḥ kumāraḥ subhagastathā kanyā śubhānanā
dṛṣṭvāścaryamidaṃ so'tha vismayaṃ paramaṃ gataḥ // 2.1.35 //
Сута:
Прекрасный мальчик и девочка прекрасноликая. Узрев это чудо, он пришел в великое изумление
36
sūta uvāca
rājne nivedayāmāsa putrau dvau tu jhaṣodbhavau
rājāpi vismayāviṣṭaḥ sutaṃ jagrāha taṃ śubham // 2.1.36 //
Сута:
И царю сообщил о детях, рожденных рыбой. Царь, наполненный удивлением, взял к себе благого мальчика.
37
sūta uvāca
sa matsyo nāma rājāsau dhārmikaḥ satyasaṇgaraḥ
vasuputro mahātejāḥ pitrā tulyaparākramaḥ // 2.1.37 //
Сута:
Он [стал известен] как царь Матсья32, праведный, правдивый в обещаниях, Сын Васу, исполненный великой доблести, равный отцу по мощи.
38
sūta uvāca
kālikā vasunā dattā tarasā jalajīvine
nāmnā kālīti vikhyātā tathā matsyodarīti ca // 2.1.38 //
Сута:
А девочку Васу вернул вскоре рыбаку, И она была известна под именем Кали33, а также Матсьодари34.
39
sūta uvāca
matsyagandheti nāmnā vai gaṇena samajāyata
vivardhamānā dāśasya gṛhe sā vāsavī śubhā // 2.1.39 //
Сута:
Из-за того, что от ее тела исходил запах рыбы, ее звали также Матсьягандха35, И она, прекрасная дочь Васу, росла в доме рыбака.
40
sūta uvāca
ṛṣaya ūcuḥ
adrikā muninā śaptā matsyī jātā varāpsarāḥ
vidāritā ca dāśena mṛtā ca bhakṣitā punaḥ // 2.1.40 //
Сута:
Лучшая из апсар Адрика, проклятая мудрецом и превратившаяся в рыбу, Была разрезана рыбаком, умерла и была съедена.
41
sūta uvāca
kiṃ babhūva punastasyā apsarāyā vadasva tat
śāpasyāntaṃ kathaṃ sūta kathaṃ svargamavāpa sā // 2.1.41 //
Сута:
[Мудрецы сказали]: Что сталось с той апсарой, расскажи об этом, Как она освободилась от проклятия и как вновь достигла рая?
42
sūta uvāca
śaptā yadā sā muninā vismitā sambabhūva ha
stutiṃ cakāra viprasya dīneva rudatī tadā // 2.1.42 //
Сута:
Проклятая мудрецом, она испугалась И восхвалила мудреца, удрученная, рыдающая.
43
sūta uvāca
dayāvānbrāhmaṇaḥ prāha tāṃ tadā rudatīṃ striyam
mā śokaṃ kuru kalyāṇi śāpāntaṃ te vadāmyaham // 2.1.43 //
Сута:
Проникнувшись состраданием, брахман сказал той рыдающей женщине: «Не печалься, о прекрасная, я расскажу тебе о том, как ты избавишься от проклятия.
44
sūta uvāca
matkrodhaśāpayogena matsyayoniṃ gatā śubhe
mānuṣau janayitvā tvaṃ śāpamokṣamavāpsyasi // 2.1.44 //
Сута:
Вследствие проклятия, вызванного моим гневом, ты войдешь в лоно рыбы, о благая, Но родив двух людей, ты освободишься от проклятия».
45
sūta uvāca
ityuktā tena sā prāpa matsyadehaṃ nadījale
bālakau janayitvā sā mṛtā muktā ca śāpataḥ // 2.1.45 //
Сута:
Услышав его слова, она вошла в тело рыбы в речной воде, И произведя на свет двух детей, умерла и освободилась от проклятия.
46
sūta uvāca
santyajya rūpaṃ matsyasya divyarūpamavāpya ca
jagāmāmaramārgaṃ ca śāpānte varavarṇinī // 2.1.46 //
Сута:
Оставив облик рыбы и обретя [вновь] божественный облик, Красавица пошла по пути бессмертных и освободилась [от довлеющего над] ней проклятия.
47
sūta uvāca
evaṃ jātā varā putrī matsyagandhā varānanā
putrīva pālyamānā sā dāśagehe vyavardhata // 2.1.47 //
Сута:
Таким образом родилась прекрасноликая дева Матсьягандха, И оберегаемая, как дочь, выросла в доме рыбака.
48
sūta uvāca
matsyagandhā tadā jātā kiśorī cātisuprabhā
tasya kāryāṇi kurvāṇā vāsavī cātisuprabhā // 2.1.48 //
Сута:
Дочь Васу, став очень прелестной девушкой, Продолжала заниматься домашними делами.
ГЛАВА ВТОРАЯ. РОЖДЕНИЕ ВЬЯСЫ
1
sūta uvāca
ekadā tīrthayātrāyāṃ vrajan pārāśaro muniḥ
ājagāma mahātejāḥ kālindyāstaṭamuttamam // 2.2.1 //
Сута:
Однажды, находясь в паломничестве по святым местам, мудрец Парашара36, Исполненный великой мощи, пришел на берег Калинди37.
2
sūta uvāca
niṣādamāha dharmātmā kurvantaṃ bhojanaṃ tadā
prāpayasva paraṃ pāraṃ kālindyā uḍupena mām // 2.2.2 //
Сута:
И попросил [он], праведный, рыбака, добывающего себе пропитание: «Перевези меня на другой берег Калинди на лодке».
3
sūta uvāca
dāśaḥ śrutvā munervākyaṃ kurvāṇo bhojanaṃ taṭe
uvāca tāṃ sutāṃ bālāṃ matsyagandhāṃ manoramām // 2.2.3 //
Сута:
Рыбак, добывающий пропитание на берегу, услышав слова мудреца, Приказал прекрасной деве Матсьягандхе:
4
sūta uvāca
uḍupena muniṃ bāle paraṃ pāraṃ nayasva ha
gantukāmo'sti dharmātmā tāpaso'yaṃ śucismite // 2.2.4 //
Сута:
«На лодке мудреца, дочка, на другой берег перевези, Хочет переправиться этот праведный аскет, о обладающая чистой улыбкой.»
5
sūta uvāca
ityuktā sā tadā pitrā matsyagandhātha vāsavī
uḍupe munimāsīnaṃ saṃvāhayati bhāminī // 2.2.5 //
Сута:
Услышав слова отца, дочь Васу Матсьягандха Стала перевозить севшего в лодку мудреца, красавица.
6
sūta uvāca
vrajan sūryasutātoye bhāvitvāddaivayogataḥ
kāmārtastu munirjāto dṛṣṭvā tāṃ cārulocanām // 2.2.6 //
Сута:
Мудрец, плывущий [в лодке] по водам Ямуны, под действием неотвратимой судьбы38, Стал мучимым страстью, увидев ее, обладающую чарующими очами.
7
sūta uvāca
grahītukāmaḥ sa munirdṛṣṭvā vyanjitayauvanām
dakṣiṇena kareṇaināmaspṛśaddakṣiṇe kare // 2.2.7 //
Сута:
Видя ее и желая ей, полной юности, насладиться, Он коснулся своей правой рукой ее правой руки.
8
sūta uvāca
tamuvācāsitāpāṇgī smitapūrvamidaṃ vacaḥ
kulasya sadṛśaṃ vaḥ kiṃ śrutasya tapasaśca kim // 2.2.8 //
Сута:
Ему же она молвила, улыбаясь, следующие слова: «Разве подобное уместно для твоего рода, твоего знания Шрути39 и твоего подвижничества.
9
sūta uvāca

gatvā gajāhvayaṃ rājā cakārotsavamuttamam

Приехав в Город Слона107, царь [Шантану] устроил пышное празднество, И призвав астролога, спросил его о благоприятном дне108.

stryuvāca
samāhṛtya prajāḥ sarvāḥ sacivānsarvaśaḥ śubhān

Собрав всех подданных и советников, царь Назначил Гангею [своим] наследником.

stryuvāca
kṛtvā taṃ yuvarājānaṃ putraṃ sarvaguṇānvitam

Провозгласив сына, наделенного всеми добродетелями, [своим] наследником, Счастья достиг праведный [Шантану] и не вспоминал [больше] Джахнави.

sūta uvāca
etadvaḥ kathitaṃ sarvaṃ kāraṇaṃ vasuśāpajam

Ганга:
Итак, я рассказал все о причине проклятия Васу, А также о рождении Гангеи и рождении Джахнави,
66
sūta uvāca
gaṇgāvataraṇaṃ puṇyaṃ vasūnāṃ sambhavaṃ tathā
yaḥ śṛṇoti naraḥ pāpānmucyate nātra saṃśayaḥ // 2.4.66 //
Ганга:
О благом нисхождении Ганги и также о рождении Васу. Человек, который слушает [эти истории], освобождается от греха, нет в этом сомнения.

sūta uvāca
puṇyaṃ pavitramākhyānaṃ kathitaṃ munisattamāḥ
yathā mayā śrutaṃ vyāsātpurāṇaṃ vedasammitam // 2.4.67 //
Ганга:
Я возвестил вам чистое, очищающее повествование, о лучшие из мудрецов, Как слышал ее от Вьясы, Пурану, равную Ведам109.
68
sūta uvāca
śrīmadbhāgavataṃ puṇyaṃ nānākhyānakathānvitam
dvaipāyanamukhodbhūtaṃ pancalakṣaṇasaṃyutam // 2.4.68 //
Ганга:
Шримад-Бхагавата чистую, содержащую разнообразные истории, Изошедшую из уст Дваипаяны, включающую пять элементов110.
69
sūta uvāca
śṛṇvatāṃ sarvapāpaghnaṃ śubhadaṃ sukhadaṃ tathā
itihāsamimaṃ puṇyaṃ kīrtitaṃ munisattamāḥ // 2.4.69 //
Ганга:
У слушающих ее она уничтожает грехи, дарует [им] благо и низводит [на них] счастье. Итак, сообщена [вам] эта итихаса111, о лучшие из мудрецов.
ГЛАВА ПЯТАЯ. ВЫДАЧА ЗАМУЖ САТЬЯВАТИ
1
ṛṣaya ūcuḥ
vasūnāṃ sambhavaḥ sūta kathitaḥ śāpakāraṇāt
gāṇgeyasya tathotpattiḥ kathitā lomaharṣaṇe // 2.5.1 //
Мудрецы:
Ты рассказал, о Сута, о рождении Васу вследствие проклятия [мудреца], И о рождении Гангеи, о сын Ломахаршаны.
2
mātā vyāsasya dharmajna nāmnā satyavatī satī
kathaṃ śantanunā prāptā bhāryā gandhavatī śubhā // 2.5.2 //
Мудрецы:
Но как , о знаток дхармы, Шантану сочетался браком С матерью Вьясы по имени Сатьявати, целомудренной, источающей запах, благой?
3
tanmamācakṣva vistāraṃ dāśaputrī kathaṃ dhṛtā
rājnā dharmavariṣṭhena saṃśayaṃ chindhi suvrata // 2.5.3 //
Мудрецы:
То расскажи подробно, как дочь рыбака была избрана в жены Царем, лучшим из знатоков Дхармы, рассей же сомнение, о давший благой обет.
4
sūta uvāca
śantanurnāma rājarṣirmṛgayānirataḥ sadā
vanaṃ jagāma nighnanvai mṛgāṃśca mahiṣān rurūn // 2.5.4 //
Сута:
Царь-мудрец по имени Шантану, любящий охоту, Постоянно выезжал в лес, убивая зверей: буйволов, оленей и [и других].
5
sūta uvāca
catvāryeva tu varṣāṇi putreṇa saha bhūpatiḥ
ramamāṇaḥ sukhaṃ prāpa kumāreṇa yathā haraḥ // 2.5.5 //
Сута:
Четыре года так вместе с сыном царь Наслаждался счастьем, как Хара с Кумарой.112
6
sūta uvāca
ekadā vikṣipanbāṇānvinighnankhaḍgasūkarān
sa kadācidvanaṃ prāptaḥ kālindīṃ saritāṃ varām // 2.5.6 //
Сута:
Однажды, пуская стрелы и убивая носорогов и вепрей, Он заехал далеко в лес и достиг Калинди, лучшей из рек.
7
sūta uvāca
mahīpatiranirdeśyamājighradgandhamuttamam
tasya prabhavamanvicchansajancacāra vanaṃ tadā // 2.5.7 //
Сута:
Царь почувствовал превосходный запах, который нельзя описать в словах, И тогда, усердно ища его [источник], он бродил по лесу.
8
sūta uvāca
na mandārasya gandho'yaṃ mṛganābhimadasya na
campakasya na mālatyā na ketakyā manoharaḥ // 2.5.8 //
Сута:
Этот ароматный запах не был [запахом] ни кораллового дерева , ни мускуса из пупков оленей113, Ни дерева чампаки114, ни жасмина , ни кетаки115.
9
sūta uvāca
na cānubhūtapūrvo'yaṃ vāti gandhavahaḥ śubhaḥ
kuto'yameti vāyurvai mama ghrāṇavimohanaḥ // 2.5.9 //
Сута:
Но воздух был насыщен этим запахом.
10
sūta uvāca
iti sancintyamāno'sau babhrāma vanamaṇḍalam
mohito gandhalobhena śantanuḥ pavanānugaḥ // 2.5.10 //
Сута:
Так думая, Шантану бродил кругом по лесу, Сбитый с толку этим запахом, сопровождаемый ветром.
11
sūta uvāca
sa dadarśa nadītīre saṃsthitāṃ cārudarśanām
śṛṇgārarahitāṃ kāntāṃ susthitāṃ malināmbarām // 2.5.11 //
Сута:
Затем он заметил деву, восседающую на берегу реки, Очаровательного облика, возбуждающую страсть, [но облаченную] в грязные одежды.
12
sūta uvāca
dṛṣṭvā tāmasitāpāṇgīṃ vismitaḥ sa mahīpatiḥ
asyā dehasya gandho'yamiti sanjātaniścayaḥ // 2.5.12 //
Сута:
Увидев ее, смотрящую искоса, удивленный царь Решил, что этот запах исходит от ее тела.
13
sūta uvāca
tadadbhutaṃ rūpamatīva sundaraṃ
tathaiva gandho'khilalokasammataḥ
vayaśca tādṛṇ navayauvanaṃ śubhaṃ
dṛṣṭvaiva rājā kila vismito'bhavat // 2.5.13 //
Сута:
Ее красота и привлекательность были удивительны, ее запах приводил в восхищение весь мир, Ее возраст соответствовал юности, и она источала благость, увидев ее, царь пришел в изумление.
14
sūta uvāca
keyaṃ kuto vā samupāgatādhunā
devāṇganā vā kimu mānuṣī vā
gandharvaputrī kila nāgakanyā
jāne kathaṃ gandhavatīṃ nu kāminīm // 2.5.14 //
Сута:
«Кто ты и откуда ты пришла, богиня ли ты или земная женщина, Дочь гандхарвов или дочь нагов?»
15
sūta uvāca
sancintya caivaṃ manasā nṛpo'sau
na niścayaṃ prāpa yadā tataḥ svayam
gaṇgāṃ smarankāmavaśaṃ gato'tha
papraccha kāntāṃ taṭasaṃsthitāṃ ca // 2.5.15 //
Сута:
Размышляя, царь так и не пришел к определенному выводу, И вспоминающий Гангу, подпавший под власть Камы, он спросил деву, сидящую на берегу:
16
sūta uvāca
kāsi priye kasya sutāsi kasmā
diha sthitā tvaṃ vijane varoru
ekākinī kiṃ vada cārunetre
vivāhitā vā na vivāhitāsi // 2.5.16 //
Сута:
«Кто ты, дорогая, и чья ты дочь, и почему ты сидишь здесь в одиночестве, о дивнобедрая, Скажи, о прекрасноокая, замужем ли ты или не замужем?
17
sūta uvāca
sanjātakāmo'hamarālanetre
tvāṃ vīkṣya kāntāṃ ca manoramāṃ ca
brūhi priye yāsi cikīrṣasi tvaṃ
kiṃ ceti sarvaṃ mama vistareṇa // 2.5.17 //
Сута:
Мной овладела страсть, когда я узрел тебя, деву, радующую сердце, о прекрасноокая, Расскажи, о дорогая, кто ты и что ты собираешься делать — все это подробно.»
18
sūta uvāca
ityevamuktā sudatī nṛpeṇa
provāca taṃ sasmitamambujekṣaṇā
dāśasya putrīṃ tvamavehi rājan
kanyāṃ pituḥ śāsanasaṃsthitāṃ ca // 2.5.18 //
Сута:
Услышав сказанное царем, прекраснозубая и лотосоокая ответила ему: «Знай, что я дочь рыбака, о царь, и я девушка, находящаяся во власти отца.
19
sūta uvāca
tarīmimāṃ dharmanimittameva
saṃvāhayāmīha jale nṛpendra
pitā gṛhe me'dya gato'sti kāmaṃ
satyaṃ bravīmyarthapate tavāgre // 2.5.19 //
Сута:
Во имя дхармы я перевожу [путников] в этой лодке по воде, о Индра среди царей, Отец мой сегодня отправился домой, правду тебе говорю, о обладатель богатства.
20
sūta uvāca
ityevamuktvā virarāma bālā
kāmāturastāṃ nṛpatirbabhāṣe
kurupravīraṃ kuru māṃ patiṃ tvaṃ
vṛthā na gacchennanu yauvanaṃ te // 2.5.20 //
Сута:
» Произнеся такие слова, дева замолкла, и томимый любовью, сказал ей царь: «Выходи замуж за меня, первого среди героев [рода] Куру, и не напрасно пройдет твоя молодость.
21
sūta uvāca
na cāsti patnī mama vai dvitīyā
tvaṃ dharmapatnī bhava me mṛgākṣi
dāso'smi te'haṃ vaśagaḥ sadaiva
manobhavastāpayati priye mām // 2.5.21 //
Сута:
Нет у меня супруги, так стань же моей законной женой, моей второй половиной116, о обладающая глазами олененка, Я раб твой, я в твоей власти, Манобхава117 мучает меня, о дорогая.
22
sūta uvāca
gatā priyā māṃ parihṛtya kāntā
nānyā vṛtāhaṃ vidhuro'smi kānte
tvāṃ vīkṣya sarvāvayavātiramyāṃ
mano hi jātaṃ vivaśaṃ madīyam // 2.5.22 //
Сута:
Ушла супруга [прежняя] моя, бросив меня, и не найдя другой жены, я одинок, о любимая. Смотря на тебя, прекрасную во всех членах, ум стал беспокойным мой.»
23
uvāca
śrutvāmṛtāsvādarasaṃ nṛpasya
vaco'tiramyaṃ khalu dāśakanyā
kṛtvātidhairyaṃ nṛpatiṃ sugandhā // 2.5.23 //
Сута:
Услышав подобные амрите118 прекрасные слова царя, дочь рыбака Ответила царю, наделенная саттвической природой, источающая прекрасный запах, сохраняя великое терпение:
24
uvāca
yadāttha rājan mayi tattathaiva
manye'hametattu yathā vacaste
nāsmi svatantrā tvamavehi kāmaṃ
dātā pitā me'rthaya taṃ tvamāśu // 2.5.24 //
Сута:
«Как ты мне сказал, о царь, так и я также думаю, Но я не независима, знай, охотно выдаст меня замуж отец мой, его попроси поскорей.
25
uvāca
na svairiṇīhāsmyapi dāśaputrī
piturvaśe'haṃ satataṃ carāmi
sa ceddadāti prathitaḥ pitā me
gṛhāṇa pāṇiṃ vaśagāsmi te'ham // 2.5.25 //
Сута:
Хотя я и дочь рыбака, но я не поступаю по собственной воле, воле отца я следую всегда, И если, попрошенный [тобой], отец отдаст меня, то возьми мою руку, в твоей власти я [буду] тогда.
26
uvāca
manobhavastvāṃ nṛpa kiṃ dunoti
yathā punarmāṃ navayauvanāṃ ca
dunoti tatrāpi hi rakṣaṇīyā
dhṛtiḥ kulācāraparamparāsu // 2.5.26 //
Сута:
Манматха не мучает тебя, как меня, наделенную юностью, Но тем не менее я должна сохранять верность обычаям [своего] рода, передающимся из поколение в поколение.
27
sūta uvāca
ityākarṇya vacastasyā nṛpati kāmamohitaḥ
gato dāśapatergehaṃ tasyā yācanahetave // 2.5.27 //
Сута:
» Сута сказал: Услышав ее слова, царь, сбитый с толку страстью, Отправился в дом царя рыбаков, чтобы попросить [руки его дочери].
28
sūta uvāca
dṛṣṭvā nṛpatimāyāntaṃ dāśo'tivismayaṃ gataḥ
praṇāmaṃ nṛpateḥ kṛtvā kṛtānjalirabhāṣata // 2.5.28 //
Сута:
Увидев пришедшего царя, рыбак очень удивился, И поклонившись царю, сложивши ладони, промолвил.
29
dāśa uvāca
dāso'smi tava bhūpāla kṛtārtho'haṃ tavāgame
ājnāṃ dehi mahārāja yadarthamiha cāgamaḥ // 2.5.29 //
Рыбак:
Я твой раб, о царь, и я осчастливлен твоим приходом, Скажи же, о великий царь, ради чего ты пришел сюда.
30
dāśa uvāca
rājovāca
dharmapatnīṃ kariṣyāmi sutāmetāṃ tavānagha
tvayā ceddīyate mahyaṃ satyametadbravīmi te // 2.5.30 //
Царь:
Я сделаю твою дочь своей законной женой, о безгрешный, Если ты отдашь ее мне, правду тебе я говорю.
31
dāśa uvāca
kanyāratnaṃ madīyaṃ cedyattvaṃ prārthayase nṛpa
dātavyaṃ tu pradāsyāmi na tvadeyaṃ kadācana // 2.5.31 //
Рыбак:
Если ты просишь мою дочь-сокровище, о царь, Которую должно выдать замуж, то я отдам ее тебе, я не могу ее не отдать.
32
dāśa uvāca
tasyāḥ putro mahārāja tvadante pṛthivīpatiḥ
sarvathā cābhiṣektavyo nānyaḥ putrastaveti vai // 2.5.32 //
Рыбак:
Но ее сын, о великий царь, после твоей кончины как царь Должен быть помазан, и никакой другой сын твой».
33
sūta uvāca
śrutvāvākyaṃ tu dāśasya rājā cintāturo'bhavat
gāṇgeyaṃ manasā kṛtvā novāca nṛpatistadā // 2.5.33 //
Рыбак:
Услышав слова рыбака, царь был озадачен, И вспоминая Гангею, ничего тогда он не ответил.
34
sūta uvāca
kāmāturo gṛhaṃ prāptaścintāviṣṭo mahīpatiḥ
na sasnau bubhuje nātha na suṣvāpa gṛhaṃ gataḥ // 2.5.34 //
Рыбак:
Мучимый страстью, взволнованный, царь тогда возвратился домой, Но придя домой, он не сделал омовения, не поел и не заснул.
35
sūta uvāca
cintāturaṃ tu taṃ dṛṣṭvā putro devavratastadā
gatvāpṛcchanmahīpālaṃ tadasantoṣakāraṇam // 2.5.35 //
Рыбак:
Увидев, что он озабочен, его сын Деваврата119, Подойдя, спросил царя, чем он расстроен.
36
sūta uvāca
durjayaḥ ko'sti śatruste karomi vaśagaṃ tava
kā cintā nṛpaśārdūla satyaṃ vada nṛpottama // 2.5.36 //
Рыбак:
«Кто твой враг, что не может быть побежден, я подчиню его тебе, Какая забота у тебя, о тигр среди царей, правду скажи, о лучший из царей.
37
sūta uvāca
kiṃ tena jātena sutena rājan
duḥkhaṃ na jānāti na nāśayedyaḥ
ṛṇaṃ grahītuṃ samupāgato'sau
prāgjanmajaṃ nātra vicāraṇāsti // 2.5.37 //
Рыбак:
Зачем нужен [такой] сын, о царь, который не знает горя [своего отца] и не может ему помочь? Он должен отдавать долги, созданные в прошлых жизнях, и не должно быть раздумий здесь.
38
sūta uvāca
vimucya rājyaṃ raghunandano'pi
tātājnayā dāśarathistu rāmaḥ
vanaṃ gato lakṣmaṇajānakībhyāṃ
sahaiva śailaṃ kila citrakūṭam // 2.5.38 //
Рыбак:
Оставив царство, сын Дашаратхи, радость [рода] Рагху Рама, по приказу отца, Ушел в лес вместе с Лакшманой и Джанаки на гору Читракута120.
39
sūta uvāca
suto hariścandranṛpasya rājan
yo rohitaśceti prasiddhanāmā
krīto'tha pitrā vipaṇodyataśca
dāsārpito vipragṛhe tu nūnam // 2.5.39 //
Рыбак:
Знаменитый сын царя Харишчандры по имени Рохита, о царь, Согласился быть проданным и был слугой в доме брахмана.121
40
sūta uvāca
tathājigartasya suto variṣṭho
nāmnā śunaḥśepa iti prasiddhaḥ
krītastu pitrāpyatha yūpabaddhaḥ
sammocito gādhisutena paścāt // 2.5.40 //
Рыбак:
А прославленный и прекрасный сын Аджигартхи по имени Шунахшепа Был продан отцом и даже привязан к жертвенному столбу, а затем был освобожден сыном Гадхи.122
41
sūta uvāca
pitrājnayā jāmadagnyena pūrvaṃ
chinnaṃ śiro māturiti prasiddham
akāryamapyācaritaṃ ca tena
guroranujnā ca garīyasī kṛtā // 2.5.41 //
Рыбак:
Известно, что некогда по приказу отца сын Джамадагни отрубил голову [своей] матери. Это неслыханное деяние он совершил, считая приказ отца более важным.123
42
sūta uvāca
idaṃ śarīraṃ tava bhūpate na
kṣamo'smi nūnaṃ vada kiṃ karomyaham
na śocanīyaṃ mayi vartamāne
'pyasādhyamarthaṃ pratipādayāmyadaḥ // 2.5.42 //
Рыбак:
Это [мое] тело в твоем [распоряжении], скажи мне, что мне сделать, Ты не должен печалиться, пока я жив, и трудновыполнимое исполню я.
43
sūta uvāca
prabrūhi rājaṃstava kāsti cintā
nivārayāmyadya dhanurgṛhītvā
dehena me ceccaritārthatā vā

После окропления водой ньягродха стала такой же прекрасной, как и прежде, И Такшака удивился, увидев упавшее дерево.
15
sūta uvāca
tamāha kaśyapaṃ nāgaḥ kimarthaṃ te pariśramaḥ
sampādayāmi taṃ kāmaṃ brūhi vāḍava vānchitam // 2.10.15 //

Змей сказал Кашьяпе: «Ради чего твое старание? Скажи мне, чего ты хочешь, и я исполню это».

kaśyapa uvāca
vittārthī nṛpatiṃ matvā śaptaṃ pannaga niḥsṛtaḥ

Сута:
Жаждя богатства и зная, что царь проклят, о змей, я вышел Из дома, чтобы помочь благодаря своему знанию царю [и получить обильное богатство].

vittaṃ gṛhāṇa viprendra yāvadicchasi pārthivāt

Бери же богатство, о Индра среди брахманов264, сколько ты хотел от царя, Столько я и дам тебе, но [прежде] ступай в свой дом, и мое намерение тоже осуществится.
18
sūta uvāca
tacchrutvā vacanaṃ tasya kaśyapaḥ paramārthavit

Услышав его слова, Кашьяпа, знающий истину, Задумался: «Что же делать мне?

sūta uvāca
dhanaṃ gahītvā svagṛhaṃ prayāmi yadyahaṃ punaḥ

20
sūta uvāca
jīvite'tha nṛpaśreṣṭhe kīrtiḥ syādacalā mama

21
sūta uvāca
rakṣaṇīyaṃ yaśaḥ kāmaṃ dhigdhanaṃ yaśasā vinā

Да добуду же я славу, не нужно богатство без славы, Прежде Рагху все отдал брахманам ради славы265.
22

hariścandreṇa karṇena kīrtyarthaṃ bahuvistaram
upekṣeyaṃ kathaṃ bhūpaṃ dahyamānaṃ viṣāgninā // 2.10.22 //
Сута:
Харишчандра и Карна огромное [богатство раздали] ради славы266, И как я могу бросить в беде царя, сжигаемого огнем яда?
23
sūta uvāca
jīvite'dya mayā rājni sukhaṃ sarvajanasya ca
arājake prajānāśo bhavitā nātra saṃśayaḥ // 2.10.23 //
Сута:
Если я верну царя к жизни, то весь народ будет счастлив, А лишившись царя, подданные погибнут, без сомнения.
24
sūta uvāca
prajānāśasya pāpaṃ me bhaviṣyati mṛte nṛpe
apakīrtiśca lokeṣu dhanalobhādbhaviṣyati // 2.10.24 //
Сута:
Из-за гибели подданных грех мне будет после смерти царя, И позор среди людей из-за жадности к богатству падет на мою голову».
25
sūta uvāca
iti sancintya manasā dhyānaṃ kṛtvā sa kaśyapaḥ
gatāyuṣaṃ ca nṛpatiṃ jnātavāmbuddhimattaraḥ // 2.10.25 //

Таким образом поразмыслив и погрузившись в созерцание, Кашьяпа узнал, что срок жизни царя истек.
26
sūta uvāca
āsannamṛtyuṃ rājānaṃ jnātvā dhyānena kaśyapaḥ
gṛhaṃ yayau sa dharmātmā dhanamādāya takṣakāt // 2.10.26 //
Сута:
Узнав благодаря созерцанию, что смерть царя неизбежна, Кашьяпа Вернулся в свой дом, праведный, взяв богатство, [данное] Такшакой.
27
sūta uvāca
nivartya kaśyapaṃ sarpaḥ saptame divase nṛpam
hantukāmo jagāmāśu nagaraṃ nāgasāhvayam // 2.10.27 //
Сута:
Отстранив Кашьяпу, змей, желающий умервить царя, На седьмой день пришел в город Слона.
28
sūta uvāca
śuśrāva nagarasyānte prāsādasthaṃ parīkṣitam
maṇimantrauṣadhaiḥ kāmaṃ rakṣyamāṇamatandritam // 2.10.28 //
Сута:
Вблизи города он услышал, что Парикшит находится во дворце И усердно охраняется благодаря драгоценным камням, мантрам и лекарственным травам.
29
sūta uvāca
cintāviṣṭastadā nāgo vipraśāpabhayākulaḥ
cintayāmāsa yogena praviśeyaṃ gṛhaṃ katham // 2.10.29 //
Сута:
Тогда озадаченный змей, наполненный страхом перед проклятием брахмана, Подумал: «Как я могу проникнуть во дворец?
30
sūta uvāca
vanjayāmi kathaṃ cainaṃ rājānaṃ pāpakāriṇam
vipraśāpāddhataṃ mūḍhaṃ viprapīḍākaraṃ śaṭham // 2.10.30 //
Сута:
Как я обману этого царя-грешника, Глупого и коварного, причинившего страдание брахману и брахманом проклятого.
31
sūta uvāca
pāṇḍavānāṃ kule jātaḥ ko'pi naitādṛśo bhavet
tāpasasya gale yena mṛtaḥ sarpo niveśitaḥ // 2.10.31 //
Сута:
В роду пандавов не рождался еще подобный этому, Который поместил мертвую змею вокруг шеи подвижника.
32
sūta uvāca
kṛtvā vigarhitaṃ karma jānankālagatiṃ nṛpaḥ
rakṣakānbhavane kṛtvā prāsādamabhigamya ca // 2.10.32 //
Сута:
Совершив порицаемое деяние и зная о приближении смерти, царь, Поставив стражников вокруг дворца и войдя во дворец,
33
sūta uvāca
mṛtyuṃ vancayate rājā vartate'dya nirākulaḥ
taṃ kathaṃ dhakṣayiṣyāmi vipravākyena coditaḥ // 2.10.33 //
Сута:
Обманул смерть и пребывает там безмятежно. Так как же я сожгу его, побуждаемый словами брахмана?
34
sūta uvāca
na jānāti ca mandātmā maraṇaṃ hyanivartanam
tenāsau rakṣakānsthāpya saudhārūḍho'dya modate // 2.10.34 //
Сута:
Он, слабый духом, не знает о неотвратимости смерти, И из-за этого, расставив стражников и войдя во дворец, сейчас радуется.
35
sūta uvāca
yadi vai vihito mṛtyurdaivenāmitatejasā
sa kathaṃ parivarteta kṛtairyatnaistu koṭibhiḥ // 2.10.35 //
Сута:
Если смерть предначертана неодолимой Судьбой267, То как он может отвратить ее, хотя бы предпринимая десять миллионов попыток?
36
sūta uvāca
pāṇḍavasya ca dāyādo jānanmṛtyuṃ gataṃ nṛpaḥ
jīvane matimāsthāya sthitaḥ sthāne nirākulaḥ // 2.10.36 //
Сута:
[Этот] царь, потомок пандавов, зная, что смерть уже близка, И все еще думая о жизни, пребывает безмятежно во дворце.
37
sūta uvāca
dānapuṇyādikaṃ rājā kartumarhati sarvathā
dharmeṇa hanyate vyādhiryenāyuḥ śāśvataṃ bhavet // 2.10.37 //
Сута:
Царь должен заниматься благотворительностью и совершать другие деяния, приносящие заслуги. Благодаря дхарме исчезают болезни и жизнь бывает долгой.
38
sūta uvāca
nocenmṛtyuvidhiṃ kṛtvā snānadānādikāḥ kriyāḥ
maraṇaṃ svargalokāya narakāyānyathā bhavetū // 2.10.38 //
Сута:
Человек, к которому приблизилась смерть, должен совершать омовение, заниматься благотворительностью и ожидать времени смерти, Тогда, умирая, он идет в Сваргалоку, [а если не делает этого] — то в ад.
39
sūta uvāca
dvijapīḍākṛtaṃ pāpaṃ pṛthagvāsya ca bhūpateḥ
vipraśāpastathā ghora āsanne maraṇe kila // 2.10.39 //
Сута:
Этот царь совершил великий грех, причинив страдание брахману, И ужасно проклятие брахмана, когда смерть близка.
40
sūta uvāca
na ko'pi brāhmaṇaḥ pārśve ya enaṃ pratibodhayet
vedhasā vihito mṛtyuranivāryastu sarvathā // 2.10.40 //
Сута:
Нет поблизости брахмана, который бы открыл бы ему на это глаза, Творцом [ему] предопределена смерть неотвратимая.
41
sūta uvāca
iti sancintya sarpo'sau svānnāgānnikaṭe sthitān
kṛtvā tāpasaveṣāṃstānprāhiṇotsubhujaṇgamān // 2.10.41 //
Сута:
Так поразмыслив, тот змей, [собрав] змей, находящихся поблизости, И превратил их в подвижников.
42
sūta uvāca
phalamūlādikaṃ gṛhya rājne nāgo'tha takṣakaḥ
svayaṃ ca kīṭarūpeṇa phalamadhye sasāra ha // 2.10.42 //
Сута:
Дав им плоды и корни [для передачи] царю, змей Такшака Сам в облике червя ползал между плодами.
43
sūta uvāca
nirgatāste tadā nāgāḥ phalānyādāya satvarāḥ
te rājabhavanaṃ prāpya sthitāḥ prāsādasannidhau // 2.10.43 //
Сута:
Затем, взяв плоды, змеи поспешно пошли, И достигнув царского дворца, встали поблизости от него.
44
sūta uvāca
rakṣakāstāpasāndṛṣṭvā papracchustaccikīrṣitam
ūcuste bhūpatiṃ draṣṭuṃ prāptāḥ smo'dya tapovanāt // 2.10.44 //
Сута:
Стражники, увидев аскетов, спросили их об их намерениях, И они ответили: «Мы пришли из леса подвижничества, чтобы увидеть царя,
45
sūta uvāca
abhimanyusutaṃ vīraṃ kulārkaṃ cārudarśanam
parivardhayituṃ prāptā mantrairātharvaṇaistathā // 2.10.45 //
Сута:
Сына Абхиманью, солнце рода [Куру], обладающего чарующим обликом, Мы пришли, чтобы продлить его жизнь благодаря мантрам из Атхарваведы268.
46
sūta uvāca
nivedayadhvaṃ rājānaṃ darśanārthāgatānmunīn
kṛtvābhiṣekānyāsyāmo dattvā miṣṭaphalānica // 2.10.46 //
Сута:
Сообщите же царю, что мудрецы пришли, чтобы увидеть его, И мы пойдем [к нему], чтобы окропить его водой и дать ему сладких плодов.
47
sūta uvāca
bhāratānāṃ kule vāpi na dṛṣṭā dvārarakṣakāḥ
na śrutaṃ tāpasānāṃ tu rājno'sandarśanaṃ kila // 2.10.47 //
Сута:
Мы никогда не видели стражников у дверей [дворца] рода потомков Бхараты269, И не слышали о том, чтобы подвижники не могли встретиться с царем.
48
sūta uvāca
ārohāmo vayaṃ tatra yatra rājā parīkṣitaḥ
āśīrbhirvardhayitvainaṃ dattājnāḥ pravrajāmahe // 2.10.48 //
Сута:
Мы поднимемся туда, где [находится] царь Парикшит, Благословениями укрепив его и дав ему наставления, мы уйдем восвояси».
49
sūta uvāca
ityākarṇya vacasteṣāṃ tāpasānāṃ tu rakṣakāḥ
pratyūcustān dvijānmatvā nideśaṃ bhūpateryathā // 2.10.49 //
Сута:
Услышав слова аскетов, стражники Ответили им, брахманам, помня приказ царя:
50
sūta uvāca
nādya vo darśanaṃ viprā rājnaḥ syāditi no matiḥ
śvaḥ sarvatāpasairatra tvāgantavyaṃ nṛpālaye // 2.10.50 //
Сута:
«Невозможна сейчас встреча с царем –таково наше мнение, о брахманы, Все аскеты пусть приходят завтра к обители царя.
51
sūta uvāca
anārohastu prāsādo viprāṇāṃ munisattamāḥ
vipraśāpabhayādrājnā vihito'sti na saṃśayaḥ // 2.10.51 //
Сута:
Брахманам воспрещен вход в этот дворец, о лучшие из мудрецов, Из-за страха царя перед проклятием брахмана он был построен, без сомнения».
52
sūta uvāca
tadocustānatho viprāḥ phalamūlajalāni ca
viprāśiṣaśca rājne'tha grāhayantu surakṣakāḥ // 2.10.52 //
Сута:
Тогда им сказали брахманы: «Плоды, коренья и воду И благословения брахманов царю передайте, о добрые стражники».
53
sūta uvāca
te gatvā nṛpatiṃ procustāpasānāgatānjanāḥ
rājovācānayadhvaṃ vai phalamūlādikaṃ ca yat // 2.10.53 //
Сута:
Они, сходив к царю, сообщили о пришедших подвижниках, И царь сказал: «Принесите плоды, коренья и прочее.
54
sūta uvāca
pṛcchadhvaṃ tāpasānkāryaṃ prātarāgamanaṃ punaḥ
praṇāmaṃ kathayadhvaṃ me nādya sandarśanaṃ mama // 2.10.54 //
Сута:
Спросите, что они собираются делать, и передайте им от меня поклоны. Сегодня я не могу увидиться с ними, пусть приходят [завтра] утром.
55
sūta uvāca
te gatvātha samādāya phalamūlādikaṃ ca yat
rājne samarpayāmāsurbahumānapuraḥsaram // 2.10.55 //
Сута:
[Стражники], сходив к [аскетам] и взяв у них плоды, коренья и прочее, Предложили их с великим почтением царю.
56
sūta uvāca
gateṣu teṣu nāgeṣu vipraveṣāvṛteṣu ca
phalānyādāya rājāsau sacivānidamabravīt // 2.10.56 //
Сута:
После того как змеи в облике брахманов ушли, Царь взял плоды и сказал придворным
57
sūta uvāca
suhṛdo bhakṣayantvadya phalānyetāni sarvaśaḥ
admyahaṃ caikametadvai phalaṃ viprārpitaṃ mahat // 2.10.57 //
Сута:
«Друзья, ешьте эти плоды! А я съем один большой плод из принесенных брахманами».
58
sūta uvāca
ityuktvā tatphalaṃ dattvā suhṛdbhyaścottarāsutaḥ
kare kṛtvā phalaṃ pakvaṃ dadāra nṛpatiḥ svayam // 2.10.58 //
Сута:
Произнеся такие слова и раздав плоды друзьям, сын Уттары, Царь взял сам себе спелый плод.
59
sūta uvāca
vidāritaṃ phalaṃ rājnā tatra kṛmirabhūdaṇuḥ
sa kṛṣṇanayanastāmro dṛṣṭo bhūpatinā svayam // 2.10.59 //
Сута:
Разрезав плод, царь увидел маленького червя, Черноглазого, [с телом] цвета меди.
60
sūta uvāca
taṃ dṛṣṭvā nṛpatiḥ prāha sacivānvismitānatha
astamabhyeti savitā viṣādadya na me bhayam // 2.10.60 //
Сута:
Увидев его, царь сказал удивленным придворным: «Солнце заходит, и нет у меня [больше] страха перед ядом.
61
sūta uvāca
aṇgīkaromi taṃ śāpaṃ kṛmiko māṃ daśatvayam
evamuktvā sa rājendro grīvāyāṃ saṃnyaveśayat // 2.10.61 //
Сута:
Я принимаю проклятие, червяк этот пусть укусит меня». () Произнеся такие слова, Индра среди царей поместил его на свою шею.
62
sūta uvāca
astaṃ yāte divānāthe dhṛtaḥ kaṇṭhe'tha kīṭakaḥ
takṣakastu tadā jātaḥ kālarūpī bhayānakaḥ // 2.10.62 //
Сута:
Когда Солнце закатывалась, помещенный на горло червь Превратился в ужасного Такшаку, олицетворенную смерть.
63
sūta uvāca
rājā saṃveṣṭitastena daṣṭaścāpi mahīpatiḥ
mantriṇo vismayaṃ prāptā rurudurbhṛśaduḥkhitāḥ // 2.10.63 //
Сута:
Он обвился вокруг царя и ужалил его, И изумленные придворные, исполненные великого горя, зарыдали.
64
sūta uvāca
ghorarūpamahiṃ vīkṣya dudruvuste bhayārditāḥ
cukruśū rakṣakāḥ sarve hāhākāro mahānabhūt // 2.10.64 //
Сута:
Увидев чудовищного змея, они разбежались, терзаемые страхом. Закричали все стражники, и вопль великий раздался.
65
sūta uvāca
veṣṭito bhogibhogena vinaṣṭabahupauruṣaḥ
novāca nṛpatiḥ kincinna cacālottarāsutaḥ // 2.10.65 //
Сута:
Обвитый змеем и потерявший мужество, Царь, сын Уттары, ничего не сказал и не шелохнулся.
66
sūta uvāca
utthitāgniśikhā ghorā viṣajā takṣakānanāt
prajajvāla nṛpaṃ tvāśu gataprāṇaṃ cakāra ha // 2.10.66 //
Сута:
Из пасти Такшаки изошли ужасные ядовитые огненные стрелы, И он сжег [ими] царя и лишил его жизни.
67
sūta uvāca
hatvāśu jīvitaṃ rājnastakṣako gagane gataḥ
jagaddagdhaṃ tu kurvāṇaṃ dadṛśustaṃ janā iha // 2.10.67 //
Сута:
Забрав жизнь царя, Такшака взмыл в небо, И его, как будто бы собирающегося сжечь мир, увидели люди.
68
sūta uvāca
sa papāta gataprāṇo rājā dagdha iva drumaḥ
cukuśuśca janāḥ sarve mṛtaṃ dṛṣṭvā narādhipam // 2.10.68 //
Сута:
Царь, лишившись жизни, упал, как сожженное дерево, И все люди закричали, увидев, что государь мертв.

1
sūta uvāca
gataprāṇaṃ tu rājānaṃ bālaṃ putraṃ samīkṣya ca
cakruśca mantriṇaḥ sarve paralokasya satkriyāḥ // 2.11.1 //
Сута:
Видя, что царь мертв и его сын еще ребенок, Придворные совершили погребальные обряды.
2

Приняв такое решение, дева стала будить мудреца: «Настало время сандхьи, вставай, вставай, о давший благой обет!»
45
vyāsa uvāca
utthito'sau muniḥ kopāttāmuvāca vrajāmyaham
tvaṃ tu bhrātṛgṛhaṃ yāhi nidrāvicchedakāriṇī // 2.12.45 //
Вьяса:
Проснувшийся мудрец в гневе сказал ей: «Я ухожу, А ты, прервавшая мой сон, ступай в дом брата».
46
vyāsa uvāca
vepamānābravīdvākyamityuktā muninā tadā
bhrātrā dattā yadarthaṃ tatkathaṃ syādamitaprabha // 2.12.46 //
Вьяса:
Услышав слова, сказанные мудрецом, она спросила его, дрожа: «Для чего мой брат отдал меня в жены, и что будет от этого, о исполненный неизмеримого блеска?»
47
vyāsa uvāca
muniḥ prāha jaratkāruṃ tadastīti nirākulaḥ
gatā sā muninā tyaktā vāsukeḥ sadanaṃ tadā // 2.12.47 //
Вьяса:
Мудрец ответил безмятежно: «То есть [у тебя во чреве]», И она, покинутая мудрецом, отправилась во дворец Васуки.
48
vyāsa uvāca
pṛṣṭā bhrātrābravīdvākyaṃ yathoktaṃ patinā tadā
astītyuktvā ca hitvā māṃ gato'sau munisattamaḥ // 2.12.48 //
Вьяса:
Спрошенная братом, она молвила так же, как молвил ее супруг: «Есть», — так сказав и покинув меня, лучший из мудрецов ушел».
49
vyāsa uvāca
vāsukistu tadākarṇya satyāvāṇmunirityuta
viśvāsaṃ ca paraṃ kṛtvā bhaginīṃ tāṃ samāśrayat // 2.12.49 //
Вьяса:
Услышав это, Васуки [подумал]: «Мудрец правдив», И доверяя в высшей степени своей сестре, он дал ей прибежище.
50
vyāsa uvāca
tataḥ kālena kiyatā jāto'sau munibālakaḥ
āstīka iti nāmāsau vikhyātaḥ kurusattama // 2.12.50 //
Вьяса:
Затем, по прошествии времени родился Прославленный сын мудреца по имени Астика, о лучший из Куру.
51
vyāsa uvāca
tenāyaṃ rakṣito yajnastava pārthivasattama
mātṛpakṣasya rakṣārthaṃ muninā bhāvitātmanā // 2.12.51 //
Вьяса:
И он, мудрец, знающий истину, остановил твое жертвоприношение, О лучший из царей, ради спасения родичей матери.
52
vyāsa uvāca
bhavyaṃ kṛtaṃ mahārāja mānito'yaṃ tvayā muniḥ
yāyāvarakulotpano vāsukerbhaginīsutaḥ // 2.12.52 //
Вьяса:
Ты сделал хорошо, о великий царь, что принял [во внимание] слова мудреца, Происходящего из рода Яявары, сына сестры Васуки.
53
vyāsa uvāca
svasti te'stu mahābāho bhārataṃ sakalaṃ śrutam
dānāni bahu dattāni pūjitā munayastathā // 2.12.53 //
Вьяса:
Благо тебе, о сильнорукий, ты целиком выслушал [Маха]бхарату, Раздал многочисленные дары и воздал почести мудрецам.
54
vyāsa uvāca
kṛtena sukṛtenāpi na pitā svargatiṃ gataḥ
pāvitaṃ na kulaṃ kṛtsnaṃ tvayā bhūpatisattama // 2.12.54 //
Вьяса:
Но благодаря твоим добрым деяниям [твой] отец не достиг рая, И ты не очистил целиком твою семью, о лучший из Бхарат.
55
vyāsa uvāca
devyāścāyatanaṃ bhūpa vistīrṇaṃ kuru bhaktitaḥ
yena vai sakalā siddhistava syājjanamejaya // 2.12.55 //
Вьяса:
Построй же, о царь, с преданностью огромный храм Богини, И ты обретешь все сиддхи313, о Джанамеджая.
56
vyāsa uvāca
pūjitā parayā bhaktyā śivā sakaladā sadā
kulavṛddhiṃ karotyeva rājyaṃ ca susthiraṃ sadā // 2.12.56 //
Вьяса:
Почитаемая с высшей преданностью, Благая [Богиня], исполнительница всех [желаний], Способствует увеличению семьи и укреплению царства.
57
vyāsa uvāca
devīmakhaṃ vidhānena kṛtvā pārthivasattama
śrīmadbhāgavataṃ nāma purāṇaṃ paramaṃ śṛṇu // 2.12.57 //
Вьяса:
Совершив в соответствии с предписаниями жертвоприношение Богине, о лучший из царей, Выслушай высшую Пурану, называющуюся Шримад-Бхагавата.
58
vyāsa uvāca
tvāmahaṃ śrāvayiṣyāmi kathāṃ paramapāvanīm
saṃsāratāriṇīṃ divyāṃ nānārasasamāhṛtām // 2.12.58 //
Вьяса:
Я поведаю тебе повествование, очищающие в высшей степени, Переносящее через [океан] сансары314, божественное, полное многочисленных рас315. Не существует другого, что следует слушать, кроме как этой Пураны на земле, И не существует другого, что следует почитать, кроме как лотосные стопы Богини.
59
vyāsa uvāca
na śrotavyaṃ paraṃ cāsmātpurāṇādvidyate bhuvi
nārādhyaṃ vidyate rājandevīpādāmbujādṛte // 2.12.59 //
Вьяса:
Те удачливы, мудры и счастливы, В чьих сердцах, наполненных любовью, постоянно живет Богиня.
60
vyāsa uvāca
te sabhāgyāḥ kṛtaprajnā dhanyāste nṛpasattama
yeṣāṃ citte sadā devī vasati premasaṇkule // 2.12.60 //
Вьяса:
И те всегда очень несчастливы на земле, о потомок Бхараты, Кто не поклоняется Махамайе, Амбике.
61
vyāsa uvāca
suduḥkhitāste dṛśyante bhuvi bhārata bhārate
nārādhitā mahāmāyā yairjanaiśca sadāmbikā // 2.12.61 //
Вьяса:
В то время как Брахма и другие боги заняты служением ей, [Найдется] ли такой человек, который бы не стал поклоняться ей?
62
vyāsa uvāca
brahmādayaḥ surāḥ sarve yadārādhanatatparāḥ
vartante sarvadā rājaṃstāṃ na seveta ko janaḥ // 2.12.62 //
Вьяса:
Кто слушает постоянно эту [пурану], того все желания исполняются, И ее, величайшую, Бхагавати возвестила Вишну.
63
vyāsa uvāca
ya idaṃ śṛṇuyānnityaṃ sarvānkāmānavāpnuyāt
bhagavatyā samākhyātaṃ viṣṇave yadanuttamam // 2.12.63 //
Вьяса:
Благодаря слушанию ее, о царь, ты обретешь мир в сердце, И благодаря тому, что ты слушаешь Пурану, [твои] предки достигнут рая.
