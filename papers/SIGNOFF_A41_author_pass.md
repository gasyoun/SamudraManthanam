## 2. Substance flags carried (not fixed)

1. **Stale count inside the draft-status block.** The opening status entry still says "the `jsonl/` directory currently holds **155** `.jsonl` files; the 7 post-report additions are excluded", while the later entries in the same block, the frontmatter `data_source`, §3.1, §11 row 1 and the Data section all say 274 files / 126 extras / 219,463 records (re-counted 04-09-2026). It is a preserved log line, but a referee reading top-down meets 155 before 274.
2. **Two dated headers with different `Created` dates.** Line 1 carries `_Created: 25-08-2026 …_` and the line under the H1 carries `_Created: 26-06-2026 …_`. The 26-06-2026 date matches the scaffolding date in the status block; the 25-08-2026 line looks hook-added. A human should decide which one stays.
3. **§11 row 10c status contradicts §9 and the status block.** Row 10c still ends "⬜ dataset DOI still owed", but the dataset DOI was minted 28-08-2026 (H2611) per the status block, §9 item 1 and the Data availability note. Table cell, so not touched.
4. **§11 row numbering runs 9, 10b, 10c, 10.** Either the annotation-comparison row should be 10a or the rights/checklist rows should be renumbered; a table edit, so left alone.
5. **Uncited reference entry.** Hellwig & Nehrdich 2018 (Sanskrit word segmentation, EMNLP) appears in the References but is not cited anywhere in the body (only "Hellwig" for the DCS is). Either cite it in §6.2 where segmentation quality is discussed, or drop it. Reference entry, so not touched.
6. **Abstract "1788 → present" vs §2/§5 "1788–2016".** The Gītā span is stated three ways (present / 2016 / "~230 years"). Consistent enough for a draft, but a copy-editor will ask.
7. **`sa` 78,220 vs headline 78,219.** §4.1 whole-corpus `sa` role count is one more than the clean-pair headline; the single Sanskrit-only block in §4.2 explains it, but the paper never says so in one place. A one-clause footnote at §4.1 would close it (substance, so proposed only).
8. **§3.6 "86 `parallel-ru` texts" against "148 sources".** The chronology crosswalk counts texts, the corpus counts sources; the unit difference is not explained where the 86 first appears.
9. **"References ⬜" heading and the "⬜ A38, A42, A43 self-citations" line.** Open placeholders in a section a referee reads; left as tracker markers (heading text and a list item, both untouched by this pass) but they must go before any submission.
10. **Venue-dependent voice.** Every "we" is now "I" (call 3). If the chosen venue is one that expects the plural even for sole authors, the change reverts in one search-and-replace; nothing else depends on it.
