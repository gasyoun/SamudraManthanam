# Права на тексты и доступ к данным

Корпус собирает **опубликованные издания и переводы**, права на которые
принадлежат их авторам, переводчикам и издательствам. Поэтому:

- корпус открыт для **поиска и чтения онлайн** — с любого устройства,
  бесплатно;
- **массовые выгрузки данных не распространяются** — это осознанное решение,
  уважающее права на тексты;
- цитируйте найденное по правилам научного цитирования
  ([[../guide/как_цитировать]]) со ссылкой на издание-источник.

Нашли ошибку в тексте? На платформе есть система предложения исправлений —
каждое рассматривается вручную (см. [[../guide/что_такое_корпус]]).
