# Какие тексты есть в корпусе?

Сейчас в корпусе **148 активных источников** трёх типов:

- **119 стихотворных** — эпос, пураны, гимны и другие метрические тексты;
- **15 словарных** — словарные материалы с несколькими системами письма на
  строку;
- **14 прозаических**.

Каждый источник размечен и доступен через [[../guide/как_искать|поиск]] и
читалку. Состав растёт — платформа развивается открыто, история изменений
в [репозитории](https://github.com/gasyoun/SamudraManthanam).
