# Что такое параллельный корпус

**Самудра-мантхана** («Пахтание океана») — публичная исследовательская
платформа [Общества ревнителей санскрита](https://samskrtam.ru) для работы с
параллельными санскритско-русскими текстами. Название — метафора: извлечение
смысла из океана слов.

Три слоя платформы:

1. **Быстрый поиск** — полнотекстовый поиск по санскритским текстам и русским
   переводам: обычный, по регулярным выражениям и морфологический (с
   расширением по основе и корню). Подробнее: [[как_искать]].
2. **Читалка** — рабочее место для чтения текста в контексте: навигация по
   главам, устойчивые ссылки на строку, инструменты цитирования
   ([[как_цитировать]]).
3. **Исследовательский верстак** — разбор пассажей с помощью ИИ и система
   предложения научных исправлений.

В корпусе — **148 активных источников**: 119 стихотворных, 15 словарных и
14 прозаических. Работает в браузере с любого устройства, без установки:
[samskrtam.ru/parallel-corpus](https://samskrtam.ru/parallel-corpus/).
