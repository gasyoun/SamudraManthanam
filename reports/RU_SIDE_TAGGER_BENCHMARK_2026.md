(Wave 9.1 роадмапа [ROADMAP_NKRYA_PARALLEL_RUSCORPORA_2026_2027.md](https://github.com/gasyoun/SamudraManthanam/blob/main/docs/ROADMAP_NKRYA_PARALLEL_RUSCORPORA_2026_2027.md), ruling 13):

## Метод

- **Выборка**: seed-fixed стратифицированная, seed `20261029`, 3 источника
  across epochs/registers, по 1000 токенов (группы перемешиваются
  детерминированным shuffle, токены берутся в порядке групп):
  - `bhagavadgita-1788` — 1788 г., старая орфография (ять, ъ), архаичный прозаический регистр;
  - `buddhacharita-balmont` — нач. XX в. (К. Бальмонт), поэтический регистр;
  - `03_ramayana-aranyakanda` — современная научная прозаическая серия.
  Итого 3000 токенов; digest конвейера выборка+разметка `3ce63ede2370c3f5f6f02dfea514636f`.
- **Стек**: **pymorphy3 2.0.6, top-1 parse** (детерминированный базовый
  линейн; pymorphy2 не установлен на этом исполнителе — pymorphy3 есть его
  поддерживаемый близнец на том же словаре OpenCorpora). **DeepPavlov
  morphology на этом проходе не запущен**: estate-клон живёт на Mac
  (`/Users/mac/Documents/GitHub/DeepPavlov`), скачивание моделей офлайн
  недоступно на этом исполнителе (Windows); natasha/navec/slovnet не
  установлены по той же причине. «One more current stack only if cheaply
  runnable offline» — такового нет, зафиксировано явно, а не молча. Якорь
  сравнения с ВКР-эпохой — сама цифра 47% и выжившие артефакты
  `nkrya-parallel/diplom-rubanova/` (в т.ч. `deeppavlov_parsing.ipynb`).
- **Gold**: (a) для санскритизмов — сам W3-слой (`sanskritisms`: Сёренсен
  9460 + однотомный указатель МБх т.3 через `paradigms.py`, фильтрация ровно
  как в `extract.py`); (b) hand-adjudicated слайс ≤500 токенов: 270 строк
  (все 120 layer-совпавших санскритизмов + 150 общих токенов), бинарные
  приговоры «правильно/неправильно в контексте» вынесены исполнителем H6401
  по дампу с ±1 токеном контекста (`adjudication_dump.csv` →
  `adjudication_verdicts.csv`; неперечисленные id = признаны верными).
- **Оверлей**: на layer-совпавших токенах лемма принудительно берётся из
  W3-слоя (sorted-first forced pick; `narrow_candidates` на этой выборке
  снял неоднозначность во всех 120 случаях — ambiguity rate 0.0).
- **Детерминизм**: `selfcheck` (двойной прогон выборка+разметка+слайс) — PASS.

сломанный класс для общего таггера ( фиктивные стемы «раван», «сит»,
«икшвак», «ваджрать-VERB», «пандусовъ»); оверлей W3-слоя поднимает
adjudicated-срез на **+24.2 п.п. до 84.2%**.

## Расхождение авто- и adjudicated-чисел (почему оба приведены)

Авто-gold считает pymorphy верным, если его лемма входит в кандидаты слоя;
на layer-ложных срабатываниях (см. ниже) «gold» сам неверен, и там, где
pymorphy прав, а слой нет («И», «Земли», «Или»), авто-число наоборот
занижает/завышает. Adjudicated-слайс — валидационный якорь; расхождение
(56.7% против 60.0%) укладывается в ±1 такую категорию ошибок и объяснено
по-строчно в `adjudication_verdicts.csv`.

## Оговорки оценщика (estimator caveats)

1. **Top-1 без контекста**: DeepPavlov/Natasha-класс использовал бы
   контекстное снятие омонимии; наш прогон — детерминированный словарный
   top-1. Сравнение с ВКР честно именно в этом классе (её базовая — тот же
   pymorphy-класс), но это нижняя граница для нейросетевых стеков.
2. **n = 120 санскритизмов** → CI ±9 п.п.; цифра порядковая, воспроизводимая
   и датируемая — не interviewed-миллион. Слайс adjudication 270 ≤ 500 по
   контракту.
3. **Adjudicator = исполнитель H6401 (LLM-воркер)**, бинарные приговоры;
   пограничные случаи засчитаны в пользу таггера, если выбор защитим
   (напр. «Все→всё»). Это человеко-не-сертифицированный суд — потому оба
   файла (дамп+приговоры) закоммичены для перепроверки.
4. **Layer-ложные срабатывания: 19/120 = 15.8%** — капитализированные
   «И»/«Или»/«Земли» (поэтическая капитализация пробивает
   §3.3.1-stage-5 exemption) и парадигматическая коллизия «васу→васа».
   Оверлей обязан их не портить: для 9.2 нужны (i) подавление
   однословых/общеупотребительных капитализированных FP, (ii) запрет
   парадигм «-у→-а» для нерусских словоизменений.
5. **1788-страт**: дореформенная орфография ломает и pymorphy3, и W3-слой
   (ять-формы не матчатся словарём/реверс-индексом). Для 9.2 нужен
   препроцессор нормализации ѣ→е/ъ-удаление для старых источников — иначе
   аннотация этой эпохи деградирует до ~0.47 на общей лексике.
6. **Лемма-only**: POS/морфосинтаксические показатели не ско́рены; POS
   pymorphy на OOD-токенах фиктивен (NOUN на «познаетъ») и в отчёт не идёт.
7. **Права**: закоммичены пер-токенные строки и ±1 токен контекста
   (quote-density), не бегущий текст.

## Вердикт для 9.2 (машиночитаемо: `verdict.json`)

- **Стек аннотации: pymorphy3 (top-1) + W3-санскритизм-оверлей** —
  единственный дёшево воспроизводимый офлайн на исполнителях кор пула;
  DeepPavlov-прогон остаётся желательным уточнением на Mac-исполнителе.
- Обязательные дополнения, вскрытые бенчмарком: препроцессор дореформенной
  орфографии (страт 1788) и подавление layer-FP классов «И»/«Земля»/«васу».
